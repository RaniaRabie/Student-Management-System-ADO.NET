# Student-Management-System-ADO.NET

A console-based application built using ADO.NET to manage students and departments.

## Features
- View students with their departments (JOIN)
- Insert new students
- Update existing students (with optional fields)
- Delete students with confirmation
- Input validation and error handling

## Technologies Used
- C#
- ADO.NET
- SQL Server

## Key Concepts
- SqlConnection, SqlCommand, SqlDataReader
- CRUD operations
- Parameterized queries
- Data validation
